# CA Pankaj Goyal — GitHub Portfolio v1

A premium, responsive personal portfolio for GitHub Pages using a navy + gold executive visual system.

## Included
- `index.html` — complete single-page interactive portfolio
- `assets/profile.jpg` — supplied profile photograph
- `assets/CA-Pankaj-Goyal-Resume.pdf` — supplied resume, linked to View CV and Download CV

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `pankaj-goyal-portfolio`.
2. Upload everything in this folder while preserving the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will generate the live portfolio URL.

## Customization
The contact email, phone number, LinkedIn URL, resume and profile image are already wired into the HTML. Edit the `index.html` content if you want to add GitHub, projects, certifications, or additional links.
